# Portfolio Website

This is my personal portfolio website showcasing the work I have done, skills, and the projects I have developed. The website includes details about my experience, skills, and various projects I've worked on, including full-stack development, UI/UX design, and more.

## Features

- **Project Showcase**: Displays the projects I’ve worked on with descriptions, links, and videos of work.
- **Skills Section**: Highlights the technologies I specialize in, including Front-end and Back-end skills.
- **Contact Information**: Allows users to get in touch with me through contact forms or links to my social media profiles.
- **Admin Panel (for TIPS-G Alwar)**: Manage registered users, track their exam results, and post blogs.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript, React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Admin Panel**: Integrated with full functionalities like managing users, exams, and posts.
- **Other**: Git, GitHub, AOS (Animation On Scroll)
