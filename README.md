# Abhishek Sain Portfolio

Premium personal portfolio for Abhishek Sain, built with Next.js, TypeScript, Tailwind CSS, Framer Motion, GSAP, and React Three Fiber.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Edit Profile Content

Most portfolio content lives in:

```text
lib/profile.ts
```

LinkedIn public access was blocked by an auth wall while creating this project, so missing role, education, testimonial, and achievement details are polished placeholders.

## Build

```bash
npm run build
npm start
```
